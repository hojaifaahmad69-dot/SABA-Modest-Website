SOCIAL LINKS
Open js/settings.js and replace the four placeholder links.

ORDERING
Product orders use Messenger only.
WhatsApp is only a contact/social link.
There is no cart, checkout, payment or size field.

PRODUCTS
Edit js/products.js to change product name, price, image, fabric, colour, description and stock.
stock:true = Available
stock:false = Sold Out

The product cards are written directly in index.html so the images/cards appear without depending on JavaScript rendering.
